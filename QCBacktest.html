Project Overview

This automated pipeline transforms raw QuantConnect backtest results into actionable insights through a comprehensive ETL process and interactive dashboard. The system provides comparative performance metrics across differing criteria.

ETL Pipeline Architecture

The automated data processing workflow:

1. Data Extraction

Pull raw JSON details from QuantConnect backtest files

2. Data Transformation

Clean and normalize data: adjust timestamps, calculate derived metrics, handle missing values

3. Performance Analysis

Compute key metrics: Sharpe ratio, drawdowns, percent profitable, trade statistics

4. Dashboard Generation

Interactive visualizations: strategy comparison, order details, equity curve & drawdown

Key Features

Comparative analysis of multiple strategy criteria

  • Strategy Comparison: Side-by-side evaluation of multiple backtests
  • Trade Analysis: Detailed examination of individual trade execution
  • Parameter Optimization: Visualization of parameter sensitivity
  • Custom Metrics: Strategy-specific performance indicators

Technical Implementation

The system leverages modern data science tools:

  • Data Processing: Pandas for ETL operations with custom data quality checks
  • Table Visualization: Streamlit based web app for tables
  • Visualization: Plotly for interactive web-based charts
  • Analysis: Custom Python library for financial metrics calculation
